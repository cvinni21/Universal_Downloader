# Chrome Web Store listing draft

- **Name:** Universal Downloader Bridge
- **Short description:** Envie uma página, link ou download do navegador ao Universal Downloader neste computador.
- **Category:** Productivity
- **Language:** Português (Brasil)
- **Homepage / support:** https://github.com/cvinni21/Universal_Downloader
- **Privacy policy:** https://github.com/cvinni21/Universal_Downloader/blob/main/PRIVACY.md
- **Single purpose:** Send a web link selected by the user from the browser to the Universal Downloader desktop app on the same PC.

## Store description

Envie uma página ou link ao Universal Downloader pelo menu de contexto do navegador. Você também pode encaminhar downloads automaticamente; essa opção vem desligada e só funciona quando você a ativa no menu da extensão.

A extensão usa o Universal Downloader para Windows e seu auxiliar local. Ela não baixa o conteúdo por conta própria: o aplicativo recebe o link e inicia o download neste computador.

## Permission explanations

- **Menu de contexto:** oferece comandos para enviar a página, um link ou uma seleção.
- **Downloads:** oferece a interceptação automática opcional. A extensão lê a URL somente quando o usuário ativa a opção, envia-a ao aplicativo local e cancela o download do navegador depois que o app confirma o recebimento.
- **Mensagens nativas:** comunica-se com o aplicativo instalado no mesmo computador.
- **Armazenamento:** salva localmente no navegador a preferência de interceptação e o último status.

## Data handling declaration

A extensão processa URLs escolhidas no menu de contexto e, somente quando ativada, URLs de downloads do navegador. Elas são enviadas ao auxiliar local, não a um serviço remoto. A interceptação vem desligada. Consulte a [política de privacidade](https://github.com/cvinni21/Universal_Downloader/blob/main/PRIVACY.md) para todos os detalhes.
